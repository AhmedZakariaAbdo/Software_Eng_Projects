## 🛠️ Projects & Libraries I Developed

### 1. **clsString Class**
Advanced string manipulation library with rich functionality including:
- Upper/Lower case conversion
- Trimming, splitting, and joining
- Vowel counting, punctuation removal
- Word counting and text formatting

### 2. **clsDate Class**
Professional date and time handling system featuring:
- Date validation and comparison
- Adding/Subtracting days, weeks, months, years
- Leap year calculation
- Business days and vacation calculations
- Calendar printing (monthly & yearly)

### 3. **clsPerson & clsEmployee**
Practical implementation of **Inheritance** and class hierarchy design.

### 4. **clsCalculator Class** *(New)*
A smart calculator class with memory and undo functionality:
- Supports Add, Subtract, Multiply, Divide
- Prevents division by zero
- `CancelLastOperation()` feature
- Full operation history tracking
