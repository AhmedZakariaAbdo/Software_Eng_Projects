# 🏦 Bank Management System (C++ Console Application)

This project is a **console-based Bank Management System** developed using **C++**.  
It represents my **first complete practical project** after finishing multiple programming levels and problem-solving exercises.

The project focuses on applying core programming concepts in a **real, working system**, rather than isolated problems.

---

## 🎯 Project Goal

The main goals of this project are:

- Transition from solving individual problems to building a complete system
- Practice structured and logical programming
- Understand how real applications:
  - Store data
  - Retrieve data
  - Update records
  - Handle user interaction

This project simulates a basic banking system that manages client accounts using persistent storage.

## ✨ System Features

The system allows the user to:

- 📋 Display all clients in a formatted table
- ➕ Add new clients with unique account numbers
- 🔍 Search for a client by account number
- ✏️ Update existing client information
- 🗑️ Delete clients with confirmation
- 💾 Save and load data from a file
- 🧭 Navigate through a clear main menu interface

---

## 🧱 Data Structure

Each client in the system contains the following data:

- Account Number
- Pin Code
- Client Name
- Phone Number
- Account Balance

Client data is organized using a `struct` to ensure clarity and proper data handling.

## ▶️ How the Program Works

1. The program starts by displaying the **Main Menu**
2. The user chooses an option (1–6)
3. The selected operation is executed
4. Data is read from or written to the file as needed
5. The user can return to the main menu or exit the program
